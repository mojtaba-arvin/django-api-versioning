# Security Policy

## Supported versions

Security fixes are applied to the latest stable release. Users should upgrade to the latest release before reporting an issue against an older version.

## Reporting a vulnerability

Please report suspected vulnerabilities privately through GitHub's **Report a vulnerability** feature:

https://github.com/mojtaba-arvin/django-api-versioning/security/advisories/new

Do not create a public issue, pull request, discussion, or commit containing exploit details, credentials, proof-of-concept payloads, or information that could expose users before a fix is available.

Include the affected package version, Python/Django/DRF versions, impact, reproduction steps, and any suggested mitigation. Use only test credentials and sanitized data.

## Disclosure

Please allow the maintainer a reasonable opportunity to investigate, prepare a fix, and coordinate disclosure before publishing technical details. There is no guaranteed response or remediation SLA; reports are reviewed as promptly as maintainer capacity allows.
